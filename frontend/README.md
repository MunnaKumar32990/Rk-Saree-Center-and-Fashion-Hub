# RK Saree & Fashion Hub — Frontend

This is the React + Vite frontend for the **RK Saree & Fashion Hub** e-commerce platform.

For full documentation, setup instructions, environment variables, and deployment guide, please refer to the [root README.md](../README.md).

## Quick Start

```bash
npm install
npm run dev
```

Runs on `http://localhost:5173` by default.

## Build for Production

```bash
npm run build
```

Built files are output to `dist/`. The `vercel.json` in this folder handles SPA routing on Vercel deployment.
